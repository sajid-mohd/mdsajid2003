# 🔥 Mini PyTorch

I'm currently building a **mini PyTorch-style automatic differentiation framework from scratch** to understand what happens underneath modern deep learning frameworks.

The project focuses on understanding concepts such as:

```text
Tensor / Value
      │
      ▼
Computation Graph
      │
      ▼
Forward Pass
      │
      ▼
Loss
      │
      ▼
Backpropagation
      │
      ▼
Gradients
      │
      ▼
Parameter Updates
      │
      ▼
Gradient Descent
```

Core concepts I'm exploring:

* Computational graphs
* Forward propagation
* Backpropagation
* Automatic differentiation
* Gradients
* Chain rule
* Parameter updates
* Gradient descent
* Neural network building blocks
* Operator overloading
* Training loops

The goal is to understand the mechanics behind frameworks such as PyTorch rather than treating automatic differentiation as a black box.
